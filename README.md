# Money

**比奇堡记账小队帮你管钱。** 名字叫 Money，图标是海绵宝宝和派大星，底栏四个角色：海绵宝宝（概览）、派大星（明细）、珊迪（统计）、蟹老板（我的）。

本机记账，不登录、不联网、不上传。日 / 月 / 年总账、支出收入分类、明细、统计都在。

## 1. 手机安装

> iPhone 上的 `.ipa` 必须用 Apple 证书签名才能安装。这台 Windows 没有 Xcode / 证书，**产不出能直接双击安装的 iPhone 包**。两条可行路线写在 [INSTALL-iOS.md](INSTALL-iOS.md)：
> - **今天就能用**：手机装网页版（添加到主屏幕，1 分钟）；
> - **要原生 App（含轻点背面）**：用 `.github/workflows/build-unsigned-ipa.yml` 在 GitHub 免费编译出未签名 IPA，再用 Sideloadly 用你的 Apple ID 签名安装（免费、7 天有效期）。源码压缩包：`../Money-iOS-source.zip`。
> - 安卓手机告诉我，我直接打 APK。

这里有两个版本：

| 版本 | 位置 | 能力 |
| --- | --- | --- |
| **网页版 PWA（现在就能装）** | `pwa/` | 装到 iPhone 桌面，全屏、数据存本机；**没有**「轻点背面」 |
| 原生 iOS（需要 Mac 或 Sideloadly） | `ios/` | 完整功能，含「轻点背面三下自动记账」、App Intents、Siri |

### 装网页版（30 秒）

1. 双击 **`start-money.bat`**（或右键 `serve.ps1` → 用 PowerShell 运行）。窗口里会显示一个地址，例如：
   `http://192.168.10.12:8766`
2. 手机连**同一个 Wi-Fi**，Safari 打开这个地址。
3. 点 Safari 底部 **分享** → **添加到主屏幕** → 名字保持 Money。
4. 桌面出现 Money 图标，点开就是全屏 App，没有地址栏。

注意：

- 这个窗口和电脑要一直开着，手机才能打开服务（数据在手机浏览器里，关掉服务数据不会丢）。
- 第一次运行 Windows 可能弹防火墙提示，选**允许专用网络**。
- 想彻底不依赖电脑：把 `pwa/` 整个文件夹拖到任意 **HTTPS 静态托管**（Netlify Drop、Vercel、GitHub Pages 都行），用那个 https 地址在手机上「添加到主屏幕」，之后就完全离线可用（Service Worker 已写好）。
- 安卓同理：Chrome 打开地址 → 菜单 → 安装应用。

### 为什么网页版没有「轻点背面」

「轻点背面」是 iOS 系统动作，只能触发系统功能或**快捷指令**，而快捷指令要调用原生 App 的 App Intent 才能静默落账，网页无法被背面轻点唤起。这是平台限制，不是实现问题。

要那个功能，只有原生版（`ios/`）：在 Mac 上用 Xcode 编译、签名、装到手机，再配一条「听写文本 → Money」快捷指令。配置步骤写在 `ios/README.md`，App 的设置页里也有。

> 如果你有 Mac，我可以按报错把原生工程调到能跑；如果只有 Windows，网页版就是最接近「直接安装」的方案。

## 2. 功能

- **概览**：今日 / 本月 / 本年三段切换；大数字是支出，下面是收入与结余；本月每日支出迷你柱图；今日 / 本月 / 本年三档并排；「花在哪」甜甜圈 + 分类占比；最近记录。
- **明细**：按月翻页；支出 / 收入 / 全部筛选；按天分组、每天小计；点任意一条进编辑（可改金额、分类、日期、备注，可删除）；自动/手动标签。
- **统计**：12 个月支出柱图（当月高亮、月均虚线）；年度分类排行；全年支出 / 收入 / 结余。
- **我的**：总笔数、记账天数、本月支出；比奇堡记账小队六人；极速保存开关；导出 CSV；载入示例数据；清空。
- **记一笔**：输入「午饭 25」「昨天打车 18.5」「咖啡三十二块」「11月20日 超市 126.4」「工资 8000」「收到红包 200」，本机规则自动识别金额、日期、收支、分类，可再手动改。
- 数据存在 `localStorage`，刷新/关掉不丢；导出 CSV 带 BOM，Excel 直接开。

## 4. 文件结构

```
Money/
├─ start-money.bat         # 双击，起本机服务（给手机访问）
├─ serve.ps1               # 服务脚本：0.0.0.0:8766，打印局域网地址
├─ pwa/
│  ├─ index.html           # 整个 App（单文件：UI + 解析 + 存储）
│  ├─ manifest.webmanifest # PWA 名称、图标、全屏
│  ├─ sw.js                # 离线缓存（改版本号发布更新）
│  ├─ icons/               # 1024/512/192/180… 全套图标
│  ├─ img/                 # 六个角色头像 + 群像
│  └─ preview/             # 上面那张四屏图
├─ ios/                    # 原生 SwiftUI 模板（Money 图标 + 角色底栏 + 轻点背面）
└─ README.md
```

## 5. 隐私

- 没有后端，`index.html` 里没有 `fetch` 请求；记账数据只在浏览器的 `localStorage`。
- 不需要账号、不申请任何系统权限；「添加到主屏幕」之后就是一个本地应用。
- 卸载：桌面上长按图标删除；数据要清空就用「我的 → 清空全部」。
- 角色插画 © Nickelodeon，仅作个人使用；这个 App 不要上架或商用。
